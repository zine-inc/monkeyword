# monkeyword Apple app

SwiftUI multiplatform client for macOS and iOS.

## Status

Phase 1 runs in mock mode only. The app reads bundled fixtures from
`apps/shared-fixtures/` and does not connect to any live API.

## Requirements

- macOS 14 or later
- iOS 17 or later
- Swift 5.10 or later

## Build

```sh
swift build
swift test
```

## Screens

Onboarding, Dashboard, Keyword Research, Rank Tracking, Backlink Analysis, Site
Audit, Competitor Analysis, Content Brief, AI Coach, and Settings.
