# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting:

1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Describe the issue and, if possible, steps to reproduce

We aim to acknowledge reports within a few business days.

## Scope

This repository contains the **open-source client applications** (macOS, iOS, Windows) and an n8n community node. They run in **mock mode** with bundled sample data and do not include backend credentials or production keys.

The hosted backend is a separate managed service and is **out of scope** for this repository. Reports about the hosted service should also go through the private reporting channel above.

## What not to include

When reporting, never paste real API keys, access tokens, or personal data into the report. Redact such values.
